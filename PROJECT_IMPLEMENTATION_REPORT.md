# Final Year Project: Week-by-Week Implementation Documentation

This repository contains the full source code and engineering documentation for **ProcureAI**: *Automated Construction & Civil Infrastructure Tender Evaluation Platform (Roads, Highways, Bridges, Commercial & Institutional Buildings)*.

The comprehensive **14-Week Academic & Technical Project Report** is available in:
👉 [**docs/WEEK_WISE_IMPLEMENTATION_REPORT.md**](./docs/WEEK_WISE_IMPLEMENTATION_REPORT.md)

### Interactive Implementation in the Platform:
You can launch and explore each week's milestones, live interactive simulators (System Architecture diagrams, Civil Relational ERD Schema, Parameter Normalization Engine, and Live MCDM Scoring Calculator) directly in the web app under the **Weekly Milestones** tab (`/weekly-tracker`).

### Quick Phase Summary (Civil & Construction Tendering):
- **Phase 1 (Weeks 1–3):** Problem Formulation, Civil Tender SRS Specifications, Multi-Tier System Architecture
- **Phase 2 (Weeks 4–9):** Construction Proposal Corpus, BOQ & Technical Preprocessing, Relational Schemas, Document Ingestion & Semantic Chunking
- **Phase 3 (Weeks 10–14):** Ingestion Validation, Civil NLP Attribute Extraction (Structural Specs, BOQ Rates, Machinery Fleet, DLP), Normalization, MCDM Weighted Scoring, Side-by-Side Comparison Matrix
- **Phase 4 (Weeks 15–16):** Final System Integration, Civil Tender PDF Reporting, and Project Defense Preparation
